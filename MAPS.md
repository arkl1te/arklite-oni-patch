Custom maps for Oni, made with Catwalk. They need **Arklite @VERSION@ or later** (and Oni with AE installed).

**Install:** 

1. unzip a map into `Oni/AE/GameDataFolder/CustomLevels/`, so you get `CustomLevels/<Map>/level50_Final.dat`. 

2. Start Oni and pick the map from **Custom Game** on the main menu. You don't strictly need to download them: when you join a server running one of these maps, the map downloads by itself.

* The maps contain no Oni textures: they load them from your own game.
